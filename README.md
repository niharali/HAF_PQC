# HAF-PQC

## Heterogeneous Algorithm Fusion for Mitigating Single-Point Cryptanalytic Failure in Post-Quantum Cryptography


## Overview

HAF-PQC is a research framework that investigates whether heterogeneous cryptographic algorithm composition can improve resilience against isolated cryptanalytic failures.

The framework combines:

- lattice-based PQC
- code-based PQC
- classical cryptography

using adaptive policy-driven selection and secure session fusion.
